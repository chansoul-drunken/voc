# BRAND METRICS

브랜드가 얼마나 검색되고 얼마나 노출되는지를 매주 같은 자로 잰다. 한 번 놓친 주차는 영원히 복원되지 않는 지표가 있어서, 착수 시점이 곧 데이터의 시작점이다.

## flow와 stock을 나눈다

| 종류 | 뜻 | 예시 | 주차 처리 |
|---|---|---|---|
| **flow** | 그 주차에 발생한 양 | 검색지수, 블로그 발행 수, 매출 | 그대로 주차값 |
| **stock** | 그 시점의 누적 스냅샷 | 리뷰 수, 팔로워, 유튜브 누적 조회수, 매장 수 | 매주 찍어 **차분** |

**stock 지표는 오늘 안 찍으면 지난주 값이 복원되지 않는다.** 우선순위가 여기 있다.

## 절대 규칙

1. **주차는 ISO 기준, 월요일 시작·일요일 종료·KST.** 모든 채널을 이 기준으로 맞춘다.
2. **이번 주는 저장하지 않는다.** 수집 시점의 이번 주는 미완성 구간이라 항상 지난주 일요일까지만 확정 저장한다.
3. **자사 글만 센다.** 브랜드명이 띄어쓰기 없이 붙어 나온 글만 집계한다. "인생 아구찜을 만났습니다"는 브랜드 언급이 아니라 감탄사다. 이 필터가 없으면 오탐이 절반을 넘는다.
4. **API 키는 환경변수로만.** `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`. 코드와 저장소에 넣지 않는다.
5. **같은 (주차, 브랜드, 지표)는 최신값으로 덮어쓴다.** 재실행이 안전해야 한다.

## 실행

```bash
python scripts/collect.py                 # 52주 소급 + 이번 주 스냅샷
python scripts/collect.py --weeks 8       # 최근 8주만 갱신
python scripts/collect.py --dry-run       # 호출만 하고 파일은 안 씀
```

출력은 `data/weekly_metrics.csv`에 append 된다.
