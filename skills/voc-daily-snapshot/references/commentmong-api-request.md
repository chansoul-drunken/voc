[제목] VOC 통합 대시보드 구축을 위한 리뷰 데이터 API 연동 문의

안녕하세요, 인생푸드입니다.
저희는 인생아구찜/어화락/삼대미역 브랜드로 댓글몽 BIZ를 이용 중이며, 사내 VOC(고객의 목소리) 통합 모니터링 대시보드를 구축하고 있습니다.

현재는 "전체 리뷰 관리" 화면의 엑셀 다운로드를 매일 수동으로 받아 반영하고 있는데, 매장 수가 많아지면서(현재 200개 이상) 자동화가 필요해졌습니다. 댓글몽에서 리뷰 데이터를 API로 제공받을 수 있는지, 가능하다면 아래 항목들을 확인하고 싶어 문의드립니다.

1. 리뷰 원문 조회 API (필수)
- 제공 가능한 필드: 리뷰ID(고유값), 매장번호, 매장명, 플랫폼(배달의민족/쿠팡이츠/요기요/땡겨요/먹깨비/네이버), 별점, 리뷰 원문, 주문메뉴, 등록일시, 답변상태(미답변/답변완료), 답변내용, 답변일시
- 조회 조건: 기간(from~to), 매장, 플랫폼, 별점 범위, 답변상태로 필터 가능한지
- 페이지네이션 지원 여부 (하루 리뷰량이 많은 경우 대응)
- 특정 시점 이후 등록/수정된 리뷰만 가져오는 증분(delta) 조회 방식 지원 여부

2. 불만족 리뷰 필터
- "불만족 리뷰 관리" 화면과 동일하게, 크리티컬 리뷰 여부 및 대응함/대응안함 상태를 API로도 받을 수 있는지

3. 매장 마스터 정보
- 매장번호, 매장명, 브랜드, 플랫폼별 연결상태를 조회하는 API가 있는지
- (점주명·연락처 등 개인정보 필드는 필요하지 않습니다)

4. 실시간 알림 (선택)
- 신규 리뷰 등록, 답변상태 변경 시 웹훅으로 알림을 받을 수 있는 방법이 있는지

5. 인증 및 기술 스펙
- 인증 방식(API Key / OAuth 등)
- Rate limit(호출 제한) 정책
- 응답 데이터 포맷(JSON 등)
- 과거 데이터 조회 가능 기간(백필 가능 범위)

6. 멀티 브랜드 지원
- 인생아구찜/어화락/삼대미역 3개 브랜드 데이터를 하나의 API 키(또는 계정)로 조회할 수 있는지, 브랜드 구분 파라미터가 있는지

7. 감성/카테고리 분류 (선택)
- 리뷰에 대한 감성분석이나 카테고리 분류 결과를 자체 제공하고 계신지 (제공되면 저희 쪽 분류 로직을 대체할 수 있어 문의드립니다)

8. 매출/주문 데이터 (선택)
- "브랜드 리뷰 현황" 화면에 있는 매출 평균, 매장별 주문 수 평균 데이터도 API로 제공되는지

API 제공이 가능하다면 이용 요금, 신청 절차, 개발 문서(Swagger/API 문서) 공유가 가능한지도 함께 안내해주시면 감사하겠습니다.
