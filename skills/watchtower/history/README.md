# history/ — 상태 파일

이 폴더의 4개 JSON이 **변동 화살표(▲▼)와 중복 방지의 유일한 근거**다.
공개 저장소에는 실측값을 넣지 않았다. 첫 실행 시 아래 빈 상태로 시작하면 된다.

| 파일 | 역할 | 지우면 |
|---|---|---|
| `rankings.json` | 주간 순위 스냅샷 | 다음 주가 "첫 회차"가 되어 화살표가 전부 NEW로 리셋 |
| `risk.json` | 일별 리스크 % | "전일 대비 ±%p"가 사라짐 |
| `seen-urls.json` | 이미 실은 출처 | 지난 기사가 다시 올라옴 |
| `viral.json` | 이미 보고한 바이럴 건 | 같은 건이 중복 보고됨 |

`rankings.json`은 주 1회 사본을 두는 게 좋다.
