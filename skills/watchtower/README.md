# WATCHTOWER 운영 안내

## 무엇이 돌아가나
| 스케줄 | 시각 | 내용 |
|---|---|---|
| `watchtower-daily-risk` | 화~일 08:00 | 자사 3브랜드 평판 리스크 + 경쟁사 악재 경보 + 바이럴 레이더 |
| `watchtower-weekly-ranking` | 월 10:00 | 위 전부 + **3개 사다리 활동량 랭킹** (그 주 종합) |

월요일 08:00에는 일간이 돌지 않는다. 월요일 10:00 주간 리포트가 그 역할까지 겸하므로 메일이 두 번 오지 않는다.

**조용한 날은 메일이 오지 않는다** (v2). 전 브랜드 안정 + 급등 없음 + 경쟁사 악재 0건 + 바이럴 70점 이상 0건이면 발송을 건너뛴다. 다만 **연속 3일 미발송이 되는 날에는 "3일간 조용했습니다" 안심 메일**이 온다 — 침묵이 "조용해서"인지 "고장나서"인지 구분되게 하기 위해서다.

## 튜닝하는 법
- **감시 대상 추가/삭제** → `config.json` 의 `ladders[].competitors` 수정. 코드 변경 불필요.
- **검색 노이즈가 심한 브랜드** → `config.json` 의 `search_hints` 에 힌트 키워드 추가.
- **점수 공식·리포트 형식·정직성 규칙** → `AGENT.md` 수정. 두 스케줄 모두 실행 시 이 파일을 읽으므로 한 곳만 고치면 된다.
- **시각 변경** → Claude에게 "watchtower 일간을 7시로 바꿔줘" 라고 말하면 된다.

## 상태 파일 (건드리지 말 것)
`history/` 안의 4개 JSON이 **변동 화살표(▲▼)와 중복 방지의 유일한 근거**다.
- `rankings.json` — 주간 순위 스냅샷. 지우면 다음 주가 다시 "첫 회차"가 되어 화살표가 전부 NEW로 리셋된다. **주 1회 사본을 두는 게 좋다.**
- `risk.json` — 일별 리스크 %. 지우면 "전일 대비 ±%p"가 사라진다. 발송하지 않은 날도 `sent:false`로 기록된다.
- `seen-urls.json` — 이미 실은 출처. 지우면 지난 기사가 다시 올라온다.
- `viral.json` — 이미 보고한 바이럴 건.

## 알아둘 것
- 스케줄은 **이 앱이 켜져 있을 때** 돈다. 예정 시각에 앱이 꺼져 있었으면 다음 실행 시 밀려서 돈다.
- 주간 실행은 24개 대상을 훑지만 **배치 A/B로 분할**된다. 배치 A(자사 3 + 라인별 상위 3)를 먼저 끝내고 저장하므로, 배치 B가 실패해도 리포트는 나온다.
- 첫 주 리포트는 변동 화살표가 전부 `NEW`다. 두 번째 주(2026-08-31)부터 ▲▼가 나온다.

## v2 (2026-08-19, 5-Color 패널 3회전 반영)

전체 변경 이력은 [AGENT.md](AGENT.md) §8, 회의록은 [panel-review_WATCHTOWER_20260819.md](../panel-review_WATCHTOWER_20260819.md) 참조.

- **리스크 산식 결함 수정** — 단일 플랫폼 ★5 위기가 가중평균에 희석돼 '안정'으로 오보되던 문제. `max(가중평균, 최고단일×0.7)` 항을 넣었다. 재현 테스트에서 유튜브 고발영상 ★5 단독 케이스가 15%(안정) → 70%(경계)로 정상 포착됐다.
- **배달앱 리뷰 추가** (가중치 .28, 최대) — 이 회사 평판 위기의 1차 발화 지점. `config.json`에 `voc_endpoint`를 넣으면 켜지고, 없으면 가중치를 나머지 5개에 재분배하며 리포트에 경고를 띄운다. **연동 전까지 리스크 지수는 실제보다 낮게 나온다.**
- **"파워 랭킹" → "활동량 랭킹"** — 측정하는 건 공개 노출 활동량이지 경쟁력이 아니다. 보도자료를 많이 뿌리는 브랜드가 상위로 간다. 부정이벤트(폐점·소송·행정처분·위생 적발) −2점을 신설해 홍보 착시를 완화했다.
- **링크 검증 의무** — 게재 전 실제로 열어 확인하고, 푸터에 `링크 검증 N/M`을 남긴다.
- **"오늘의 판단" 최상단으로** — 스크롤 없이 "할 일 있음/없음"이 먼저 보인다.
- **하위 접기** — 2주 연속 무활동 브랜드는 사다리에서 한 줄로 접는다(순위·기록은 유지).
